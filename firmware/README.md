# Firmware-Pakete

Hier liegen die Firmware-Pakete für beide Displays – **Iris** (rund, 1,46″) und **Prism** (eckig, 2,8″) –, jeweils für jede Version eine Datei.

| 0.4.0-alpha.10 | ✓ | ✓ | 2026-11-10 |

Nimm die neueste Version, die für dein Gerät angeboten wird.

## Aufspielen

1. Display mit dem Datenkabel an den PC, CRONDO Studio starten.
2. Reiter **Firmware**, die passende Datei wählen, aufspielen. Das Gerät startet danach neu.
3. Während des Aufspielens nicht trennen. Bricht es ab, bleibt das Gerät im bisherigen Stand und Studio meldet den Fehler.

Eine Datei für das falsche Gerät wird abgelehnt – du kannst dabei nichts kaputt machen.

## Zurück auf eine ältere Version

Gleicher Weg wie beim Update, nur die ältere Version wählen. Deine Profile und Einstellungen bleiben erhalten.
