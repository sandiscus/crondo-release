# CRONDO Studio (PC)

CRONDO Studio richtet das Display ein: Firmware aufspielen, Fahrzeugprofil wählen, Theme setzen, Logs sichern. Den Download gibt es bei GitHub, der Link steht auf crondo.app.

## Versionen

| Version | Plattform | Datum |
|---|---|---|
| 0.4.0-alpha.14 | Windows 10/11, 64 Bit | 2026-11-15 |

Ältere Versionen bleiben verfügbar – der Rückweg ist derselbe wie beim Update, nur mit der älteren Datei.

## Installation (Windows)

1. Setup starten. Windows meldet **„unbekannter Herausgeber“** – die Datei ist nicht signiert, das ist in der Alpha so vorgesehen. Über „Weitere Informationen“ → „Trotzdem ausführen“ installieren.
2. Administratorrechte sind nicht nötig.
3. Lizenzhinweise zu allen Fremdprogrammen findest du nach der Installation im Startmenü unter **„Lizenzhinweise“**.

## Was Studio kann

Erstinstallation des Displays, Fahrzeug und Profil wählen, Firmware aufspielen und auf eine ältere Version zurück, Themes einspielen, Seiten und Akzentfarbe setzen, Logs ansehen und ein Support-Paket für die Fehlersuche erstellen.
