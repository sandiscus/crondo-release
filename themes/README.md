# Themes

Jedes Theme ändert das ganze Display: Schriften, Farben, Zeiger, Hintergründe. Elf gibt es, alle für Iris und Prism.

| Theme | Charakter |
|---|---|
| **Minimal** | dünne Schrift, Lichtband – **ab Werk eingestellt** |
| **Classic** | Segmentringe |
| **All-out** | Farbverlauf, Schaltleuchten, Karten |
| **Bunny** | Zeigerinstrument mit Kaninchen, das auf die Drehzahl reagiert |
| **Wings** | Zeigerinstrument mit Flügelmotiv |
| **Flames** | Hot Rod: Flammen, Chrom |
| **Neon Drive** | Synthwave: Sonne, Gitter, Leuchtsegmente |
| **Heritage** | klassisches Instrument: Gold, Elfenbein |
| **Blueprint** | technische Zeichnung |
| **Terrain** | topografische Karte |
| **Bloom** | Kirschblüten |

## Theme einspielen

Studio → Reiter **Einstellungen** → Theme wählen → übernehmen. Das Display prüft das Theme, bevor es annimmt, und lässt die alten Pakete nicht liegen.

**Minimal liegt immer auf dem Gerät** und lässt sich nicht entfernen: Es ist die Rückfallebene.

**Ohne Lizenz nutzbar sind drei Themes:** Minimal, Classic und All-out. Die acht aufwendigen – Bunny, Wings, Flames, Neon Drive, Heritage, Blueprint, Terrain und Bloom – brauchen eine Premium-Lizenz.

Die Akzentfarbe (acht Farben) stellst du unabhängig vom Theme ein, am Gerät oder in Studio.
